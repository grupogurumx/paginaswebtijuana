# Paginas Web Tijuana

Sitio web para Paginas Web Tijuana.

## Instalación

```bash
npm install
```

## Uso

```bash
npm start
```

## Bot de WhatsApp (open-wa)

```bash
npm run bot:install
npm run bot
```

Ver [whatsapp-bot/README.md](whatsapp-bot/README.md) para requisitos y detalles.
