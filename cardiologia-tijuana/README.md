# Cardiología Tijuana

Sitio web para [cardiologiatijuana.com](https://cardiologiatijuana.com).

Página de una sola hoja (`index.html`) con Tailwind CSS, Alpine.js y Font Awesome desde CDN; no requiere compilación.

## Vista previa

Abre `index.html` en el navegador.

## Datos pendientes de completar

Reemplazar los marcadores antes de publicar:

- Nombre, semblanza, foto, cédulas y certificación del cardiólogo (sección `#doctor`).
- Dirección y horario del consultorio (sección `#cita` y datos estructurados en `<head>`).
- Teléfono `(664) 000 0000` y número de WhatsApp `526640000000` (barra superior, botones y constante `WHATSAPP` en el script).
