# Mapa de Palabras Clave y Posicionamiento — Webmaster Tijuana

Estrategia SEO página por página y sección por sección. Cada página ataca **una palabra
clave principal** (evitando canibalización entre páginas) y un grupo de palabras clave
secundarias y long-tail.

## 1. Inicio (`index.html`)

- **Palabra clave principal:** diseño web en Tijuana
- **Secundarias:** webmaster Tijuana, páginas web Tijuana, agencia de marketing digital
  Tijuana, desarrollo web Tijuana, SEO Tijuana, agencia web Tijuana
- **Long-tail (FAQ):** cuánto cuesta una página web en Tijuana, cuánto tarda el
  desarrollo de un sitio web, qué incluye el posicionamiento SEO
- **Title:** Diseño Web en Tijuana | Webmaster Tijuana | Agencia de Marketing Digital
- **Datos estructurados:** ProfessionalService (negocio local), WebSite, FAQPage

### Posicionamiento por sección

1. **Hero (slider):** los H1 rotan los servicios estrella (desarrollo web responsive,
   diseño gráfico, redes sociales, SEO/pago por clic). Palabras clave en titulares
   visibles arriba del pliegue (_above the fold_).
2. **Beneficios:** el H2 "Agencia de Marketing y Desarrollo de Sitios Web" refuerza la
   palabra clave de agencia; el párrafo incluye "marketing digital", "publicidad
   digital" y "gestión de redes sociales" en texto natural.
3. **Servicios destacados:** 6 tarjetas cuyos H3 son exactamente las palabras clave de
   cada página de servicio, con enlace interno a cada una (distribuye autoridad y
   define la arquitectura del sitio).
4. **Testimonios:** prueba social; menciones naturales de "diseño web", "estrategia
   SEO", "tienda virtual" y "publicidad digital" dentro de las reseñas.
5. **Preguntas frecuentes:** captura búsquedas long-tail con acordeón + schema FAQPage
   (elegible para resultados enriquecidos en Google).
6. **Contacto/Cotización:** palabra clave transaccional "cotización" + NAP (nombre,
   teléfono, ubicación) consistente para SEO local.
7. **Footer:** enlaces internos con anchor text descriptivo ("Diseño de Páginas Web
   Tijuana", "Marketing Digital y SEO"...) hacia todas las páginas de servicio.

## Elementos técnicos comunes a todas las páginas

- Title único de ~50-60 caracteres con keyword al inicio y marca al final.
- Meta description única de ~150-160 caracteres con llamada a la acción.
- URL canónica absoluta y `robots: index, follow` (excepto 404: `noindex`).
- Etiquetas de geolocalización `geo.region` MX-BCN / `geo.placename` Tijuana.
- Open Graph + Twitter Cards para compartir en redes sociales.
- Un solo H1 por página; jerarquía H2/H3 correcta.
- Breadcrumbs visibles + schema BreadcrumbList (mejora el snippet en Google).
- Enlazado interno completo: inicio → servicios → portafolio → contacto.
- Botón de WhatsApp con texto prellenado por página (mejora conversión).
- `sitemap.xml` con las 9 URLs indexables y `robots.txt` apuntando al sitemap.

## Pendientes recomendados (post-lanzamiento)

1. Enviar `sitemap.xml` en Google Search Console y verificar indexación.
2. Crear la ficha de **Google Business Profile** con el mismo NAP.
3. Publicar 1-2 artículos de blog al mes atacando long-tail informacional
   ("cuánto cuesta una página web en México 2026", "mejores plataformas de
   e-commerce"...) que enlacen a las páginas de servicio.
4. Conseguir enlaces locales (directorios de Tijuana, cámaras de comercio, prensa).
5. Sustituir el formulario `mailto:` por un backend o servicio de formularios para
   mejorar la tasa de conversión.
