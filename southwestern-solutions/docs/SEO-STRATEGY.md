### After launch
1. **Settings → Permalinks:** Post name (the theme sets this automatically on first admin load after the import).
2. Install **Rank Math** or **Yoast** (optional). All fields are already filled.
3. Verify the domain in **Google Search Console** and **Bing Webmaster Tools**, then submit `/wp-sitemap.xml` (or `/sitemap_index.xml` with a plugin).
4. Add GA4 through Site Kit or GTM. Track the contact form as a conversion: the thank-you state is `?sws_sent=ok`.
5. Install a caching plugin (LiteSpeed Cache or WP Rocket) and an SMTP plugin so the form reliably delivers to info@southwesternsolutions.org.
6. Run PageSpeed Insights. Target LCP < 2.5 s, CLS < 0.1, INP < 200 ms.
