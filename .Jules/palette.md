## 2024-07-04 - Accessible Focus States on Dark Backgrounds & Anti-patterns
**Learning:** Using `focus:outline-none` on interactive elements (like icon-only buttons or mobile menus) without providing a custom focus state is a common anti-pattern that severely harms keyboard accessibility. Furthermore, standard focus rings often fail color contrast requirements on dark backgrounds (like hero sections or footers).
**Action:** When customizing focus states with Tailwind CSS, replace `focus:outline-none` with explicit `focus-visible:ring` styles. For dark backgrounds, use `focus-visible:ring-offset-gray-900` to ensure a visible contrast border between the element and the focus ring. Always include `aria-label` for icon-only interactive elements and set `aria-hidden="true"` on the icons themselves.
